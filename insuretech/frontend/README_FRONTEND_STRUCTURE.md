# Frontend initial scaffold

This file lists the initial top-level folders created for the frontend. Module internals are intentionally left empty; feature owners will add files as needed.

Folders created under `src/`:

- `app/` — App shell (App.tsx, router, store)
- `pages/` — Route-level page shells
- `features/` — Domain feature modules (auth, businesses, profiling, etc.)
- `components/` — Shared UI components
- `layout/` — Application layouts and route guards
- `hooks/` — Reusable hooks
- `api/` — Axios instance and API helpers
- `store/` — Redux store and slices
- `types/` — Shared TypeScript types
- `constants/` — Application constants
- `utils/` — Pure utilities
- `theme/` — MUI theme config
- `styles/` — Global CSS variables and resets
- `test/` — Shared test infra (MSW, render helpers)
